# Player Toca do Dragão

Distribuição dos instaladores do player para computador.

Baixe a versão Linux em [Releases](https://github.com/Sustavo/Toca-do-dragao-player/releases). Versão beta para Ubuntu 24.04 amd64, com PipeWire/PulseAudio. Windows ainda não está disponível.

Este repositório contém apenas instaladores. O código-fonte é mantido em um repositório privado.
