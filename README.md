# Player Toca do Dragão

Distribuição dos instaladores do player para computador.

Baixe a versão Linux em [Releases](https://github.com/Sustavo/Toca-do-dragao-player/releases). Versão beta para Ubuntu 24.04 amd64, com PipeWire/PulseAudio. Windows ainda não está disponível.

Este repositório contém apenas instaladores. O código-fonte é mantido em um repositório privado.

## Windows experimental

O instalador Windows 0.3.0 está disponível em [Releases](https://github.com/Sustavo/Toca-do-dragao-player/releases/tag/player-windows-v0.3.0-experimental). A instalação, interface, diagnóstico e áudio sintético foram testados automaticamente em Windows Server 2025. A captura real do Spotify em Windows 11 físico ainda precisa ser validada. O instalador não possui assinatura digital de editor.

No aplicativo, use Conexões → Exportar diagnóstico para ajudar no teste físico. Autorize novamente o Spotify para permitir a confirmação da faixa em reprodução.
